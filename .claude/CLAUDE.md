# Claude workspace guide

This repository is the FROID platform. Use the available context to produce practical outputs for product, content, and technical tasks.

## Preferred workflow
- Start with a clear brief and ask for missing details when necessary.
- Use Claude for planning and reasoning-heavy tasks.
- Use Gemini for idea expansion, research, translations, and fast iterations.

## Video production support
When creating video content, produce:
1. A concise brief with audience, objective, tone, and format.
2. A script with hook, body, CTA, and scene suggestions.
3. A set of prompts for image/video generation and editing tools.
